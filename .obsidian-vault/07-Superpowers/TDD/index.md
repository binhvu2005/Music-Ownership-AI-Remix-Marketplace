# 🧪 Superpowers — TDD Log

> Lưu lại kết quả TDD cho từng module.
> Evidence-first: chạy test trước, báo cáo sau.

## Template

```markdown
## TDD: [Module Name]
**Ngày:** YYYY-MM-DD
**Phase:** 🔴 RED → 🟢 GREEN → 🔵 REFACTOR

### 🔴 RED Phase
- Tests written: N
- All FAIL ✅ (expected)

### 🟢 GREEN Phase
- Tests passed: N/N
- Build: ✅

### 🔵 REFACTOR Phase
- Additional tests: M
- Coverage: X%

### Evidence
```test output here```
```
